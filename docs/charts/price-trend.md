## 이 차트가 답하는 질문

"이 단지 · 이 면적 타입은 지금 얼마에, 어떤 범위로 거래되고, 언제 최고가를 갱신했나?"

## 구성

| 요소 | 표현 | 이유 |
|---|---|---|
| 개별 거래 | 반투명 점 | 실제 거래를 숨기지 않는다 (이상치 포함) |
| 거래가 25~75% | 연한 띠 | "보통 이 범위에서 거래된다" — 점 수천 개보다 읽기 쉽다 |
| 중위가 | 진한 선 2px | 추세 |
| 역대 최고가 | 주황 계단선 | 신고가가 너무 흔해(마포구 19%) 점 배지보다 "최고가가 언제 올라갔나"를 흐름으로 보여준다 (docs/05 §2) |
| 신고가 | 주황 삼각형 | 색 + 모양 이중 인코딩 (색만으로 구분하지 않음) |
| 해제 거래 | 회색 ✕ (토글) | 기본 숨김 |
| 거래량 | 아래 별도 grid의 막대 | 가격과 단위가 달라 **y축 두 개를 한 차트에 겹치지 않는다**. x축(시간)만 공유 |

색: 같은 의미 = 같은 색. 파랑 계열 = 거래가 분포, 주황 = 최고가. (dataviz reference palette)

## 결정: 중위가 / 분위수는 3개월 이동 구간, 3건 미만이면 그리지 않는다

### 문제

처음에는 월별 중위가를 그렸다. 파크리오 84㎡, 2022년 거래 절벽기에 **한 달 거래가 1건**이었고 그 거래가 시세의 절반인 12억(가족 간 직거래로 추정)이라, 중위가 선이 22억 → 12억 → 22억으로 급락했다. 데이터 1건이 "추세"로 보였다.

### 선택지

| 방법 | 장점 | 단점 |
|---|---|---|
| 월별 그대로 | 단순 | 거래 적은 달에 이상치가 곧 중위가 |
| 거래 n건 미만 달은 생략 | 정직 | 거래 적은 시기에 선이 조각난다 |
| **3개월 이동 구간 + 3건 미만 생략** | 이상치 영향 감소, 선이 덜 끊김 | 급변 시점이 최대 2개월 늦게 반영 |
| 이상치 제거 (IQR 등) | 선이 깨끗 | 실제 거래를 임의로 버림, 기준 설명이 어려움 |

### 결정

3개월 이동 구간(그달 포함 직전 3개월)의 분위수, 구간 거래 3건 미만이면 null. 거래량 막대는 월별 건수 그대로.

### 결과

| 월 | 그달 거래 | 3개월 구간 | 월별 중위가 (이전) | 3개월 중위가 |
|---|---|---|---|---|
| 2022-02 | 1 | 4 | 12억대로 급락 | 22억 |
| 2022-09 | 1 | 2 | 1건 값 | 그리지 않음 |

이상치 거래는 점으로 그대로 보인다. 숨기지 않고, 추세에만 영향을 주지 않는다.
